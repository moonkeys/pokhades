★ Questions fréquentes ★
LE JEU EST-IL VRAIMENT GRATUIT ?

Oui, entièrement. C'est un projet amateur : ni achat, ni pub, ni compte à créer.

COMMENT SE PASSENT LES MISES A JOUR ?

Le jeu vérifie au lancement s'il existe une version plus récente et applique un correctif différentiel en arrière-plan. Rien à réinstaller.

WINDOWS AFFICHE UN AVERTISSEMENT

L'installeur n'est pas signé par un certificat payant, donc SmartScreen prévient. Clique sur « Informations complémentaires » puis « Exécuter quand même ».

MACOS : « DEVELOPPEUR NON IDENTIFIE »

Clic droit sur l'application → « Ouvrir » → « Ouvrir » à nouveau. Une seule fois suffit.

OU SONT MES SAUVEGARDES ?

Windows : %APPDATA%\Godot\app_userdata\Pokhades · macOS : ~/Library/Application Support/Godot/app_userdata/Pokhades. Les mises à jour n'y touchent pas.

J'AI TROUVE UN BUG

Ouvre un ticket sur le dépôt GitHub avec ta version du jeu et ce que tu faisais au moment du problème.
